# ReWear – Sustainable Fashion Marketplace

**Give pre-loved clothes another story.**

ReWear is a full-stack sustainable fashion marketplace designed to encourage clothing reuse and reduce fashion waste. It provides a platform where users can list pre-loved clothing, explore available products, submit purchase requests, and negotiate prices.

## 🌐 Live Demo

**[Visit ReWear](https://rewear-frontend-eizo.onrender.com/)**

**[GitHub Repository](https://github.com/AngelGoyal12/ReWear)**

## ✨ Features

- **User Authentication:** Secure registration and login with JWT-based authentication and bcrypt password hashing.
- **Email Verification:** Email verification during registration.
- **Product Listings:** Browse, add, and manage clothing listings.
- **Image Uploads:** Cloud-based product image storage using Cloudinary.
- **Purchase Requests:** Send and manage requests for listed products.
- **Price Negotiation:** Submit and manage price offers.
- **Order Management:** Manage purchase-related activities.
- **Password Recovery:** Reset passwords through email verification links.

## 🎯 Project Objective

ReWear aims to make sustainable fashion more accessible by giving unused clothing a second life. It combines an online marketplace with features that promote reuse, affordability, and responsible consumption.
